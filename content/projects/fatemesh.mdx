## 项目简介

**命网 · FateMesh**（[deerblock.top](https://deerblock.top)）是我独立设计并开发上线的 AI 命理智能体平台。项目融合东方命理与生成式 AI，让命理从业者能在 5 分钟内、无需一行代码地创建属于自己的 AI「灵犀」（Lingxi）——一个真正会推演、记得住每一位客户的身外化身。

平台覆盖八字、紫微斗数、塔罗牌、星盘、大六壬等东西方推演体系，支持中英双语，面向命理创作者与终端用户双端服务。

## 要解决的问题

传统命理行业线上化有两个痛点：一是命理师的时间无法规模化，一对一咨询严重受限于个人精力；二是市面上的「AI 算命」只是套壳聊天，不会真正的排盘推演，也记不住客户。FateMesh 的思路是：把推演工具（排盘、抽牌）做进 Agent 的能力层，让 AI 像命理师一样「起盘—解读—记忆」，再通过市场机制把创作者的专业能力产品化、可计费。

## 核心功能

**1. 5 分钟创建灵犀（No-Code Agent 构建）**
- 选定专业方向：塔罗、八字、紫微、占星、大六壬、心理咨询，或自定义细分领域
- 上传私有知识库文档，或直接选用内置流派体系，灵犀像本人一样研读
- 一键分享链接或上架市场，7×24 小时服务客户

**2. 会推演的 Agent，而不是只会聊天**
- 内置真实推演工具：塔罗抽牌、八字排盘、紫微排盘、大六壬起课
- 知识库 + 长期记忆：灵犀记得每一位客户的历史对话与偏好
- MCP 协议接入外部工具，让 Agent 能行动而不只是回答


![FateMesh 对话预览](/projects/fatemesh1.jpg)


**3. 创作者认证与个人主页**
- 线上申请、平台审核，正式成为认证创作者
- 独立主页：头像、简介、专长领域、服务语言，塑造专业形象

![FateMesh 创作者主页](/projects/fatemesh2.jpg)


**4. 内容工作室**
- 一键生成塔罗/命盘分析卡片、视觉素材与发布文案
- 内置模板：每日牌运、星座运势、社媒帖子、短视频脚本、直播开场白

![FateMesh 内容工作室](/projects/fatemesh3.jpg)


**5. 灵犀市场与积分激励**
- 灵犀可提交上架，进入市场与精选推荐位
- 透明计费：支持创作者承担或用户承担两种模式，无隐藏费用
- 按对话量月度结算，创作者获得积分奖励
- 热门榜单采用复合评分算法，每 6 小时重算一次（30 天对话量 35%、收藏 25%、创作者关注 20%、新上架 10%、平均评分 10%）

## 技术实现

- **前端**：React + Vite 单页应用，暗色主题设计，中英双语国际化（i18n）
- **Agent 架构**：内置推演工具 + 知识库检索（RAG）+ 长期记忆，通过 MCP 协议扩展外部工具能力
- **SEO**：完整的 Meta / Open Graph / Twitter Card / hreflang 多语言标注，支持搜索引擎收录
- **工程化**：Vite 构建产物体积约 400KB（gzip 前），首屏资源合并加载，性能可控
